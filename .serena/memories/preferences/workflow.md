# Preferências do usuário (neste projeto)

- **Comunicação: terse.** Entregar o resultado primeiro (o que mudou / o que foi medido), tabela curta quando ajudar, sem narrar processo. pt-BR.
- **Nunca commitar, pushar ou abrir PR sem pedido explícito.** Mesmo com mudanças prontas e verificadas, parar e reportar.
- **Escopo:** entregar o pedido no tamanho pedido; decisões pequenas (nome, formato, default) são minhas, com nota de uma linha no resumo.
- **Sem slop:** nada de seção de enchimento em doc, nada de arquivo novo se editar resolve, nada de abstração para uso único.
- **Visual aprovado não pode regredir**: se o design mudar, comparar com os artefatos aprovados e provar (MAE 0 / md5) antes de dizer que está pronto.
- Idioma: textos de UI e docs em pt-BR; identificadores/comentários de código em inglês (seguindo o que já existe no arquivo).
